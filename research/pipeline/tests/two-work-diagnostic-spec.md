# Pipeline v2 两件作品低成本诊断

> Fixed before generation: 2026-07-22  
> Purpose: 用最少正文检查 pipeline 是否能迁移已接受的叙事质量；不是整馆或完整单件发布验收。

## 隔离输入

运行前由权威门验证 PRD、TechDesign 与 manifest。生成者只可读取：

- `research/README.md`
- `research/meowseum-content-instruction.md`
- `research/generation-pipeline.md`
- `research/generation-tests/v1.6.1-two-work-source-pack.md`
- `research/generation-tests/v1.6.7-two-work-source-addendum.md`
- 本规格

禁止读取两件作品的任何旧 writing task、旧稿、卡片、review 或 evaluation，也不读取对话。

## 输出切片

分别为《雪中猎人》和《纳尔迈调色板》输出：

1. 研究卡摘要：只列会真正进入本切片的事实、来源编号、不确定性。
2. 写作计划：读者起点、一个核心问题、三步认知链；纳尔迈另含历史变化前 / 变化 / 物件角色 / 争议。
3. 独立卡片简介：24—100 字。
4. `30 秒先懂`：90—180 字。
5. 深层诊断：只写三个连续段落，共 450—750 字；每段必须改变上一段理解，不按“历史 / 风格 / 珍贵”列栏目。
6. `最后再看一眼`：一个具体动作和新的判断。
7. 自审：一口气复述、三段依赖、翻译腔发现、固定句式计数和事实边界。作者不得把自己的 7 项分数作为通过证据。

## 预先固定门槛

- 纳尔迈必须先让零背景读者懂上埃及 / 下埃及、统一是渐进过程、石板在其中做什么以及 Menes 争议；不能用抽象“视觉语法”替代历史。
- 雪中猎人不能硬套政治史；要从人物活动与风景关系解释它怎样改造月份图传统。
- 两篇都要有一个可复述问题、三段真实认知推进、自然中文和对象专属最后一眼。
- 卡片与快层不复用句子；每篇最多一处完整否定—转折；两篇不得共享开头或结尾骨架。
- 封存后由未参与写作的 reviewer 逐句检查心理 / 情绪、意图、历史先后、最高级与边界冲突，并实际朗读快层；reviewer 的 7 项声音至少 12/14、无 0 分。

生成结果封存后，才与《忧郁》v1.6.7 和两件旧 v1.6.7 样本比较。文字不同不算退步；核心问题、层次、历史主次、画面回收和中文自然度下降才算退步。
