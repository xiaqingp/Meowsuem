# 《秋韵：第 30 号》1.7.1 隔离首稿测试

## 目的

只测试新版“30 秒先懂”的首稿表现：先交代作品最值得理解的价值，再解释重要性并给出可见锚点；不得用修辞钩子虚构读者动作、意见、误解或注意顺序。

## 固定边界

- 只使用 run header 明列的权威指令、pipeline、留出资料包和既有研究卡。
- 禁止读取对话、memory、skills、网络、现有网页正文、旧写作计划、旧卡片、旧草稿、旧 review、其他作品目录或任何未列路径。
- 使用 `gpt-5.6-sol`，`reasoning effort: medium`。
- 只执行一次；不传入反馈，不 retry。
- 只生成 `writing-plan.json`、`card.txt`、`draft.md`；不生成 author review 或 independent reviewer。
- 产物是未审首稿，不得发布，也不得标为 PASS。

## 首稿合同

- `writing-plan.json` 先写 `primaryValueSelection`，说明首要价值、为什么优先于其他材料，以及研究卡依据。
- `quickLayerPromise` 必须有 `primaryValue`、`whyItMatters`、`visualAnchor`；`viewingAction` 仅在确实有帮助时选填。
- `claimLedger` 覆盖卡片和详情中的每项事实、观察、比较与论点，全部指向研究卡条目；不得增加或强化断言。
- `card.txt` 是 24—100 个可见字符的独立点击理由，不复用快层，不用观看命令开头。
- `draft.md` 使用母指令规定的完整详情结构；“30 秒先懂”优先解释 1950 年成熟期地面作画方法怎样把身体移动、重力、颜料流动与控制一起变成画面内容，并用疏密、覆盖、裸露画布或横向尺度中的具体证据确认。
- 禁止用“你以为、别急、先别、谁会注意、重点不在、机关不在”建立开场，也不得假定观众觉得它是乱泼、正找名牌或先注意某一元素。
- 讲清强比较作存在，因此本作是“重要藏品”，不虚构“世界唯一”或不可替代性。
- 自然中文、简明有层次；顾爷式方法体现在取舍、因果和具体解释，不体现在口头禅、假反转或密集玩梗。
