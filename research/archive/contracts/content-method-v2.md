# Museum 内容方法 v2（历史研究记录）

> 本文件只保存形成标准时的研究过程，不是生成指令。新增、重写或审核内容只使用 [Meowseum 内容生成母指令](./meowseum-content-instruction.md)。

> 状态：历史证据，已被 `meowseum-content-instruction.md` 取代；禁止用于生成或审核  
> 来源：六支 Grandpagu 顾爷博物馆视频的跨样本综合  
> 适用范围：博物馆介绍、路线建议、重点作品详情；不定义 UI。

## 内容目标

每段内容至少解决一个真实问题：

- 这家馆值不值得我专程去？
- 它最不可替代的东西是什么？
- 时间有限时，我该先看什么、跳过什么？
- 到作品前，我应该站在哪里、先看哪里、停多久？
- 哪一个事实会让我第二眼看到不同的东西？

若一段内容只增加知识，却不改变选择或观看，应下沉到“更多背景”，不占主叙事。

## 最优先原则：通俗不等于过度精简

通俗化要降低术语、句法和理解门槛，不能删除读者完成理解所必需的逻辑。任何历史关系、收藏来源、名气形成或价值判断，先写出完整链条，再考虑缩短。

### 因果链的最低完整结构

根据内容需要，至少交代：

1. **背景状态**：事情发生前是什么情况。
2. **触发事件**：谁对什么做了什么。
3. **直接后果**：因此具体改变了什么。
4. **后续事件**：作品、人物或机构后来发生了什么。
5. **与当前观看的关系**：这为什么影响作品的地位，或为什么值得观众再看一眼。

并非每段都必须机械写成五句，但不能让零背景读者自行补齐其中的关键节点。

### 压缩时可以删什么

- 重复形容词。
- 不改变观看的枝节。
- 可下沉到结构化字段的尺寸、材质和完整年表。
- 同一意思的重复例子。

### 压缩时不能删什么

- 行为主体与作用对象。
- 两个事件的先后顺序。
- 从事件到结论之间的中间后果。
- 指代对象，尤其是同时出现多件作品或多方国家时。
- “已确认事实、合理推断、编辑判断”之间的边界。

### 一句话一个关键动作

复杂关系优先拆成连续短句，不用一个“在……之后，因此……”结构塞进多个主体。短句的目的不是制造节奏，而是让读者始终知道当前是谁、在做什么。

### 时间相邻不自动等于因果

“A 发生后 B 发生”是事实顺序；“A 导致 B”需要额外证据。若只能确认历史时机相关，应写“恰好处在……的时期”“这帮助我们理解……”，不能写成确定因果。

### 零背景读者测试

假设读者不认识作品、艺术家和历史人物。读完后，他应该能复述：

- 谁对谁或对什么做了什么？
- 两件事为什么按这个顺序出现？
- 中间发生了什么变化？
- 哪部分是事实，哪部分是我们的解释？
- 这段背景为什么值得在作品前知道？

任一问题无法回答，都说明文本仍然压缩过度。

## 一、博物馆介绍结构

### 1. 一句话判断

格式：**行动建议 + 最大价值 + 主要代价。**

示例骨架：

> 如果你只想在这座城市安排一家艺术馆，选它；它拥有最完整的某类收藏，但人流和体量会让一次看全变成坏主意。

要求：

- 不以建馆年份开头。
- 读完即可初步决定去或不去。
- 明确适合谁，也允许明确不适合谁。

### 2. 场馆解释中心

每馆只选一个主轴，用一句话表达：

- 一个总比喻：MoMA 像现代艺术宗教。
- 一条人物线：博尔盖塞是收藏家与贝尼尼共同完成的剧场。
- 一种体验：圣马可是安静与长期凝视。
- 一个时代：荷兰国立展示强国怎样生活、消费和自我想象。
- 一套任务：梵蒂冈是一场需要提前规划出口的通关。

检验问题：这句话换成另一家馆是否仍然成立？若可以，说明不够独特。

### 3. 为什么这些东西会在这里

用不超过三段解释收藏形成机制，可选角度：

- 王室、国家、宗教或私人收藏。
- 战争、殖民、考古、购买、捐赠或没收。
- 建筑原始用途与后来转为博物馆的过程。
- 集中收藏某位艺术家或某一流派的原因。

不写完整馆史年表，只保留能解释今天馆藏与体验的节点。

### 4. 旅行价值

综合分数之外必须附行动语言：

| 层级 | 旅行含义 |
| --- | --- |
| 90–100 | 有很多稀世珍品，值得为了它专程来到这座城市 |
| 80–89 | 有一些稀世珍品，已在这座城市时值得主动排进行程 |
| 70–79 | 没有足以决定行程的稀世珍品，但总体浏览体验不错，可去可不去 |
| 60–69 | 有一些小众特殊看点，除此之外不建议去 |
| 60 以下 | 不建议去，首次旅行可以略过 |

分数不是普遍真理，必须同时写出：适合谁、最低建议时长、主要限制、同城替代品。

先定档，再在档位内部打分。没有稀世珍品或不可替代整体时最高 79 分；只有通过“是否值得为了它来到这座城市”的检验才可进入 90 分以上。参观体验、建筑、服务与动线只能影响档内位置，不能单独帮助场馆跨档。

档内数字的含义：下段表示刚达到该档门槛；中段表示珍品密度、主题完整性或浏览体验明显增强；上段表示多个方面都接近全球最高水平。两个场馆若只有优势类型不同、没有足够依据证明高下，可以同分，不制造一分差异。

“稀世珍品”不只指单件名作，也可以是难以替代的成组收藏、仍保留原始关系的空间，或建筑与收藏形成的完整体验。每一项都必须指向具体对象并说明不可替代的原因。

判断稀有度时，先定义“同类”再寻找最接近的第二件：比较题材、年代、原作或复制品、材料、尺度、完整度、原始位置与观看方式。第二件的存在不自动取消珍贵性，它负责限制“唯一”“罕见”的口径；随后还要解释本件在艺术成就、历史信息和现场经验上为什么仍不可替代。没有权威存世总数时，只能写“在目前核实的可比对象中”，不能制造全球数量。

研究结论与前台写法分开：后台保留比较对象、证据边界和珍贵性结论；前台把相关证据放进观看叙事，不另设“它珍贵在哪里”证明段。读者应在理解作品的过程中自然得出其价值，而不是先接受评级再阅读论证。

### 5. 时间方案

至少提供三档：

- **90–120 分钟：保底路线**——先消灭最大遗憾。
- **半天：代表路线**——理解场馆主轴。
- **一整天或二刷：兴趣路线**——选择一个文明、艺术家或时期深入。

路线不是作品编号列表。每档必须说明为何这样取舍，以及哪些作品因地理距离可顺路组合。

### 6. 放心跳过

可以明确写出：

- 虽然重要，但在别处更适合看。
- 与本馆主轴关联弱。
- 现场体验差、借展或排队成本过高。
- 只有专题兴趣者才值得投入时间。

跳过建议必须解释机会成本，不能贬低作品或文明。

### 7. 稳定内容与实时内容分层

稳定层：收藏逻辑、作品背景、观看方法、推荐理由。  
运营层：票价、预约、入口、开馆时间、展厅位置、借展、维修、人流。

运营层必须记录：

- 来源 URL。
- 最后核验日期。
- 可能失效的提示。
- 若失效，用户应去哪里重新确认。

## 二、推荐对象不只是一件作品

内容模型至少支持四类对象：

1. **单件作品**：如《蒙娜丽莎》。
2. **作品组或系列**：如莫奈《睡莲》系列、贝尼尼成长线。
3. **展厅或完整空间**：如拉斐尔房间、西斯廷礼拜堂、拿破仑三世套房。
4. **建筑与公共艺术**：如贝聿铭金字塔、《云门》。

所有对象都可进入推荐列表，但字段应按类型变化。例如空间对象需要光线、入口、最佳站位和整体观看顺序，而不必强填“创作者单一姓名”。

## 三、单件作品的核心结构

### 1. 推荐身份

一件作品可同时带多个标签，但必须区分：

- **历史关键**：改变艺术史或文明史。
- **艺术家代表**：最能体现其核心方法。
- **本馆独有**：离开这家馆很难获得同等体验。
- **现场胜过图片**：尺寸、材料、空间或移动无法被屏幕替代。
- **大众名作**：文化知名度高。
- **编辑偏爱**：承认主观选择。
- **兴趣限定**：只对特定主题用户高价值。

“有名”不能自动等于“最值得现场看”。

### 2. 第一眼：可执行观看动作

用一个动词开头：

- 站到左前方。
- 先看脚，不要先看脸。
- 退后三米。
- 绕到背后。
- 从下往上看。
- 比较画中光与真实窗户。
- 找到那只看似多余的杯子。

禁止使用无法执行的空话，如“感受精湛技艺”“体会时代精神”。

### 3. 入口：一个冲突、问题或感受

只选择一个主入口：

- 可见冲突：大家付同样的钱，为什么有人只剩半张脸？
- 感受名称：偷看感、幸福感、风、重量消失。
- 反常识问题：为什么有五条腿？
- 现场矛盾：最小的明星对着最大的画。
- 历史误会：它不是第一部法律，也不是 1789 年革命。

入口要在十五秒内成立，不能需要先读三段背景。

### 4. 改变第二眼的事实

主叙事保留一至三个事实，并满足至少一项：

- 解释眼前可见细节。
- 推翻常见误解。
- 揭示委托、权力或金钱关系。
- 解释作品为何在此地或为何如此陈列。
- 连接下一件作品或场馆主轴。

其余年代、尺寸、材质和学术争议进入结构化字段或“更多背景”。

### 5. 第二眼：再次观看

故事结束后必须回到作品：

> 现在再看远处那一点船影。希望被画得越小，木筏上的绝望才越大。

如果结尾没有让用户重新看某个细节，说明内容仍停留在故事会。

### 6. 原始语境（需要时）

回答：

- 原本为谁制作？
- 原本放在哪里？
- 原本用来做什么？
- 原始观众停留多久、从什么角度看？
- 搬进博物馆后失去了什么，又获得了什么？

祭坛画、壁画、建筑装饰、墓葬物、宫殿陈设必须优先考虑这一层。

### 7. 现场动作与停留时间

建议按观看机制给出，而非统一时长：

- **第一眼型，30–60 秒**：强调瞬间感受。
- **细节型，2–4 分钟**：寻找若干视觉证据。
- **绕行型，3–5 分钟**：雕塑或空间，需要移动。
- **沉浸型，5 分钟以上**：光线、壁画、冥想空间。

同时提示人流、距离、拍摄限制或最佳角度。

### 8. 关联下一件

优先使用关系组织作品：

- 同一艺术家的成长或变化。
- 同一题材的不同处理。
- 委托人与艺术家的冲突。
- 乡村与城市、静止与动作、名气与代表性。
- 同一路线上自然相邻。

二十件作品不应像二十篇独立百科文章。

## 四、双层阅读结构

### 第一层：30 秒先懂

必须同时回答两个问题：这件作品最值得看的是什么；观众现在应该站在哪里、先看哪里或做什么。通常约 90–180 字，但完整理解优先于字数。

第一句优先给明确判断、反常识冲突或可见感受；语气采用从顾爷样本提炼出的讲述方法——判断鲜明、问题推进、因果完整、最终回到作品——但不复制固定口头禅、评级名称或人设。

若涉及两个以上历史事件或主体，只保留观看动作与价值判断，把完整解释放进细看层，不能留下半条容易误读的因果关系。

### 第二层：愿意多停几分钟

不是一篇百科长文，而是按问题拆开的现场工具。根据作品类型选择标题，但内容角色必须完整：

- 核心艺术机制或历史机制：它具体怎样成立，而不是“技艺精湛”。
- 著名作者风格：只在作者明确且个人风格会改变观看时加入；指出线条、色彩、光线、构图、笔触、人体或材料的现场证据，并说明本作是典型、转折还是例外。匿名、工坊或归属不确定作品不强行人格化。
- 珍贵度或独特价值：稀世珍品说明比较对象与边界；其他作品解释为什么仍值得占用现场时间，不强行谈罕见。
- 原始语境与后来变化：只在能改变观看时保留。
- 至少四个可执行的细节观察；雕塑或空间优先要求移动，绘画优先要求视线顺序和局部比较。
- 最后再看一眼：把细节重新合成一个整体判断，不能停在背景故事。

通常约 450–900 字；复杂建筑、历史链条或争议作品可以更长。字数仅用于发现异常短文和重复堆砌，不能代替人工质量判断。

## 五、事实与声音标记

内部编辑时，每个关键句必须属于一种类型：

| 类型 | 写法 |
| --- | --- |
| 已核实事实 | 直接陈述，并绑定来源 |
| 合理推断 | 使用“可能、或许、由此可以理解” |
| 学术争议 | 说明主要解释及分歧，不制造唯一答案 |
| 传闻或都市传说 | 明确标记，只在有助观看时保留 |
| 编辑判断 | 使用“我们的判断、如果你更在意……” |
| 个人感受 | 只有真实作者体验时使用，不伪造“我站在现场” |

AI 生成不得虚构第一人称现场经历。

## 六、语言规则

应该：

- 具体、短句、有画面。
- 允许明确判断与温和幽默。
- 用现代经验做桥，但很快回到作品。
- 面对宗教、殖民、性别与族群议题时保留多视角。
- 承认无感和不确定性。

不应该：

- 模仿小顾的固定口头禅、评级名称或人设。
- 用贬低社会群体的方式制造亲近感。
- 把文化差异简化成“他们脑子有病”。
- 用术语堆砌权威感。
- 为每件作品强塞笑点、人生哲理或阴谋。
- 把推测写成事实，或把个人偏爱写成公认排名。

## 七、每件内容的验收清单

- [ ] 有独立的“30 秒先懂”，同时包含明确价值判断和可执行观看动作。
- [ ] 有细看层，内容按问题分段，没有把不同主题揉进一个标题。
- [ ] 细看层至少提供四个能在作品前执行的观察细节。
- [ ] 快看层与细看层分工明确，不把同一句价值判断换词重复。
- [ ] 第一屏能说明为何值得停下。
- [ ] 至少有一个现场可执行动作。
- [ ] 只有一个主要入口，不同时讲五个主题。
- [ ] 至少一个事实会改变第二眼。
- [ ] 结尾确实回到作品，而不是停在背景故事。
- [ ] 零背景读者能说清每个关键事件的主体、对象与先后关系。
- [ ] 结论需要的中间后果没有因追求简短而被删除。
- [ ] 时间相邻没有被擅自写成确定因果。
- [ ] 同段出现多个国家、人物或作品时，代词不存在歧义。
- [ ] 复杂历史宁可拆成短句，也没有压成难以解析的长句。
- [ ] 名气、重要性、代表性和个人偏爱没有混写。
- [ ] 已标明重要性级别：稀世珍品、重要藏品、特色看点或体验补充。
- [ ] 若属于稀世珍品或重要藏品，研究数据有独立、可核验的价值依据；前台已把相关内容自然写进正文，没有重复的“它珍贵在哪里”模块。
- [ ] 若属于稀世珍品，已定义比较范围并核对最近比较对象；没有可靠总数时，没有使用无边界的“极为罕见”“世界唯一”。
- [ ] 正文不仅列出比较对象，还明确回答：已确认至少多少件、哪些口径不能下结论、真正罕见的是题材本身还是保存下来的语境组合。
- [ ] 事实、推断、争议、传闻和编辑判断可区分。
- [ ] 原始观众或用途在必要时得到说明。
- [ ] 与前后作品存在路线或主题关系。
- [ ] 现场位置与运营信息有日期和失效提示。
- [ ] 来源至少包含一条博物馆官方资料。
- [ ] 删除幽默后，解释依然成立。

## 八、第一版生产流程

1. 先研究场馆，写出一句不可替代的主轴。
2. 从官方亮点、馆藏数据库和实际路线建立候选池。
3. 按历史重要性、现场感染力、本馆独特性、路线效率筛到二十件。
4. 先设计作品之间的关系和路线，再写单件正文。
5. 每件先写观看动作，再补会改变第二眼的事实。
6. 将实时运营信息拆出并单独核验。
7. 做事实审核、语气审核和现场可执行性审核。
8. 最后检查总分是否真的能转化成旅行行动。
