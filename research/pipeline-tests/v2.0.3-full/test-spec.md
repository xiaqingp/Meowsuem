## 2. Author isolation

作者只可读取：

- 本规格及 run header；
- `research/meowseum-content-instruction.md`；
- `research/generation-pipeline.md`；
- 与该件作品对应的资料包；
- 本规格中的共享 `taskAcceptance`。

作者不得读取对话、正式馆稿、任何旧写作任务、旧卡片、旧稿、旧 review 或 evaluation。《忧郁》和同题旧稿只允许独立 reviewer 在新稿封存后用于质量对照。

## 3. Shared taskAcceptance

以下门槛在写作前同时提供给作者与 reviewer；reviewer 不得临时增加作者未见的失败标准。

### 3.1 Artifact and causality

- 每件依次产生 `research-card.md -> writing-plan.json -> card.txt -> draft.md -> author-review.json -> independent-review.json`。
- 每个下游文件记录直接上游文件名与 SHA-256；时间与哈希顺序必须成立。
- 研究卡只含事实、比较、观察、不确定性和来源，不含可发布正文。
- 写作计划必须包含真实读者起点、一个对象专属核心问题、快层承诺、3—6 步认知链、不得假设、高风险断言表；适用时包含 `historicalContextPlan`。
- 作者自审不打通过分；独立 reviewer 才能给最终 verdict。

### 3.2 Published-form content

- 元数据完整：中英文名、作者或文化、国家 / 地区、年代、地点 / 状态、参观优先级、重要性、建议停留。
- 独立卡片简介 24—100 个可见字符，回答为什么值得点开；不摘取快层，不以“先看 / 再看 / 首先”等导览命令开场。
- `30 秒先懂` 通常 90—180 个可见汉字，独立回答为什么值得看、现场怎么看，并兑现一个暂时答案；70—240 只作机械异常边界。
- `多停几分钟` 不以固定栏目凑结构，围绕一个问题连续推进；正文至少 320 个可见字符只是残缺警戒线，不是质量证明。
- 至少四个可现场核对的细节；`最后再看一眼` 给出对象专属动作，并用深层形成的新认识改变第二眼。
- `事实边界` 与可点击资料链接齐全；事实边界不能事后替正文中的无依据强断言兜底。
- 访客正文不得出现研究缺口、图片许可、发布待办、测试、prompt、生成器、reviewer 或版本迁移等内部生产语言；这些信息只进入不可发布 artifact。此项为硬门。

### 3.3 Reasoning and voice

- 快层删掉后深层仍完整，深层删掉后快层仍能指导观看；卡片、快层、深层不互相改写。
- 每个深层段落必须依赖前文并改变核心问题的答案；不能把历史、风格、珍贵度排成可交换栏目。
- 中文能自然朗读和复述；不把研究字段、英文句法或抽象名词直接搬进标题和正文。
- 不使用通用开场“这件作品值得看，因为”；不把“先看……再看……”“不是……而是……”当作推进模板；访客正文最多一处完整否定—转折骨架。
- 不凭空纠正读者，不把动作升级成心理，不把画面观看顺序升级成历史先后，不把图像宣称当成已证实历史。
- 幽默若出现，必须来自对象的真实处境、尺度或制度反差；删去幽默后事实和逻辑仍成立。

### 3.4 Work-specific must-pass points

- 《雪中猎人》：用近景归猎、远处冰面活动与整体冬景回答一个问题；解释它怎样改造月份图传统；不判断猎人与狗的情绪。
- 《纳尔迈调色板》：零背景读者能懂上埃及是南部河谷、下埃及是北部三角洲；统一是渐进过程；两顶王冠和两面图像怎样服务王权宣称；Menes 身份与具体战役保留争议。
- 《秋韵：第 30 号》：不靠虚构故事；讲清地面作画、身体移动、重力与控制怎样进入眼前线网；处理成熟期与比较对象，不把随机、纽约崛起或唯一性写成口号。
- 地中美术馆整体：通过一条实际移动路线说明地下、自然光、几何庭院与三位艺术家永久作品怎样共同工作；限定为地中美术馆；不把建筑、作品与体验重复计算为多个独立稀世理由。

### 3.5 Significance

- 逐件完成艺术成就、艺术史位置、历史文化价值、稀有度 / 不可替代性、馆藏位置五维判断。
- 标为“稀世珍品”必须写出比较类别、最近比较对象、可靠证据支持的决定性差异，以及比较对象仍不能提供的核心价值。
- 若比较对象可以替代核心价值、决定性差异不足或证据未知，降为“重要藏品”；名家、巨幅、年代早、馆方精选或物理唯一均不能自动升级。
- 价值判断自然进入叙事，同时在研究卡和 review 中保留可审计结论。

## 4. Independent review

新稿封存后，独立 reviewer 才可读取：四件新 artifact、共享 `taskAcceptance`、对应资料包，以及只作质量标尺的《忧郁》v1.6.7 和同题旧样本。Reviewer 不读取作者的通过宣称，也不能因文字不同判失败。

每件 review 必须：

- 实际朗读卡片、快层、标题、段落转折与最后一眼；
- 逐句抽查心理 / 情绪、意图、历史先后、图像寓意、仪式用途、因果、最高级与不可替代性；
- 验证段落依赖与核心问题回收；
- 给出七项声音评分，每项 0—2，总分至少 12/14 且无 0 分；
- 分别给出 `mechanicalVerdict`、`factBoundaryVerdict`、`narrativeVerdict`、`nativeChineseVerdict`、`significanceVerdict` 与总 `verdict`；所有项均通过，总 verdict 才能为 `PASS`。

## 5. Test order and stop rule

1. 锁定本规格、资料包、权威文件版本与 SHA-256。
2. 运行权威门、manifest 门和因果正反夹具。
3. 作者在隔离输入下逐件生成并封存四件完整 artifact。
4. 独立 reviewer 审读；失败只退回对应作品。若两件暴露同一系统缺陷，先升级 pipeline / 共享门槛并按影响重测。
5. 运行机械门与哈希因果门并记录真实结果。
6. 仅当四件全部通过，才开始 Frye 20 件整馆因果试点。
