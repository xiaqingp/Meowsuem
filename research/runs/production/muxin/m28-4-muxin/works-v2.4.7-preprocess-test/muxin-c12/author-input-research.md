# muxin-c12 研究卡

## 身份与状态

- **中文名 / 英文名**：《生与死》 / *Life and Death*（英文名来自 run header，馆方正式英译待核）
- **作者**：木心 Mu Xin
- **年代 / 材质 / 尺寸**：2001年；纸本彩墨；17.4 × 37.9厘米。开馆展对象页约写17 × 37厘米，属于取整差异。
- **收藏与可见状态**：2015年开馆特展曾展出；现有资料未给收藏机构、馆藏编号或当前常设状态。
- **参观优先级 / 重要性**：暂定“强烈推荐 / 重要藏品候选”。题名与可见形式之间有对象专属的一手口述线索，但收藏和不可替代性证据不足。
- **建议停留**：若原作在展，约3分钟。

## 可直接确认与图像记录

- 图像入口：ArtCM开馆特展对象页及多篇木心研究/访谈转载所附本作图。
- 可靠访谈对本作的可见特征记录为：整体呈深褐色；主要形体由一块块近似岩石的体块构成；明暗块面并列；画中有一枚豆粒大小的白点。
- 朱国本把它称为“半抽象的山水画”，并明确说其中是“一块块岩石”；这是受访者解释，不把“石头”升级为馆方对象命名。
- 陈丹青转述木心指着白点说“不想死呀”，属于关于本作的作者口述转述，可支持白点与题名的关系，但不能扩大为完整寓意体系。

## 候选价值证据

- `conceptual_question`：作品把“生与死”的大题目压缩到深色块面与极小白点的关系中；该关系有作者口述转述支持，不是仅凭题名猜测。
- `formal_achievement`：访谈将块面与塞尚式体块比较，强调画面稳定、少零碎细节；这是研究者/艺术家比较意见，断言强度为中等。
- 木心以“这是勃拉姆斯呀”介绍本作的转述，可说明他曾用音乐类比画面组织；不能据此确定具体乐曲、节奏或创作意图。

## 比较与不可替代性

- **最近比较组**：同为2001年的《战争前夜》（54.8 × 10.9厘米）以及木心晚期狭长纸本风景。
- **共享价值**：小尺幅、深色景观或抽象化形态、题名参与观看。
- **差异**：《生与死》更接近2.2:1而非约5:1的狭长带状；对象专属白点及木心的口述转述使其题名—形式关系较清楚。
- **结论**：本作有独立解释价值，但尚无馆藏目录或学术比较证明其为生涯转折、唯一范例或不可替代作品；不能进入稀世珍品级。

## 关键事实与局部因果

1. 大块深色形体减少细碎叙述，使极小白点成为显著对照。
2. 作者口述转述把白点与“不想死”相连，因此题名解释可以收窄到“微小亮点在深色体块中仍被保留”；不得继续编造死亡之后、生命循环或人物心理。
3. 作品曾在开馆特展展出，但这不等于稳定馆藏或当前在展。

## 趣闻候选

- 木心曾阻止陈丹青马上翻到下一张，指给他看豆大白点，并说“不想死呀”。它直接改变本作观看，可作为合格趣闻；出处为陈丹青回忆的公开转述，正文须注明是转述而非同期录音。
