# muxin-c13 研究卡

## 身份与状态

- **中文名 / 英文名**：《废谷》 / *Desolate Valley*（英文名来自 run header，正式英译待核）
- **作者**：木心 Mu Xin
- **年代 / 材质 / 尺寸**：2004年；纸本彩墨；15.7 × 42.9厘米。
- **收藏与可见状态**：2015年开馆展二楼风景画展厅展出；公开资料未确认收藏机构、编号或当前轮换。
- **参观优先级 / 重要性**：暂定“强烈推荐 / 重要藏品候选”。它是身份清楚的晚年纸本，但尚未证明为生涯代表作或不可替代对象。
- **建议停留**：若在展，约2—3分钟。

## 可直接确认与图像记录

- 可靠图像入口：《艺术新闻》开馆报道图71；ArtCM对象页可点原图。
- 已确认：横向长幅，宽高比约2.7:1；作品被陈列在二楼小型风景画序列中。
- 一篇大众评论把画面描述为近似写实油画笔触、现代西方绘画并带综合材料观感；这些是评论判断，不是材质检测，不能把“纸本彩墨”改成油画或综合材料。
- 本轮没有取得可独立核对的高清图，因此山谷轮廓、色彩、前后景和笔触方向仍不能作为直接观察登记；入选前须补四项原始观察。

## 候选价值证据

- `artist_landmark`：2004年的明确纪年使其可以放入木心晚期风景序列；但现有来源只证明年代和展出，未证明“成熟期高峰”。
- `formal_achievement`：它不像《晴风》那样极端狭长，仍以小尺幅承载横向景观；需要高清图才能说明空间怎样组织。
- 开馆策展将二楼全部用于小型风景画，并称选择依据参考木心生前对作品的分类和展示方式；这支持它在馆内解释晚年风景实践的作用，不支持馆外最高级地位。

## 比较与不可替代性

- **最近对象**：《晴风》（1999，9.5 × 54厘米）、《生与死》（2001，17.4 × 37.9厘米）及晚年微型风景画组。
- **共享价值**：晚期、小尺幅、纸本、横向风景或半抽象景观。
- **可确认差异**：《废谷》完成于2004年，比例介于极狭长带状作品与较高的《生与死》之间；题名明确指向荒废山谷，但不得由题名补景物。
- **结论**：现有比较没有证明看过组内其他作品后仍无法获得的核心价值。适合保留为独立候选，但若与整组重复回答同一问题，馆级选择时可被合并或淘汰。

## 关键事实与局部因果

1. 明确题名、年代、材质和尺寸在多个开馆来源中一致，身份置信度高。
2. 它在小型风景展厅出现，说明馆方策展把它放在晚年风景序列中理解。
3. 对“油画笔触”或“综合材料感”的评论只能用于提出比较问题；在技术资料缺席时，不能写成制作事实。
